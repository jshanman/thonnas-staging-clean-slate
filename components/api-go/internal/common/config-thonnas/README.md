# config-thonnas (api-go)

This helper normalises the environment variables generated by `thonnas config resolve` for the Go API. It maps the exported/imported values defined in `components/api-nest/thonnas-config.json` and the corresponding secrets file to typed structs that can be consumed inside Go modules.

## Usage

```go
package main

import (
	"log"
	cfgthonnas "thonnas/api-go/internal/common/config-thonnas"
	"thonnas/api-go/internal/config"
)

func main() {
	cfg, _ := config.Load()
	w := cfgthonnas.NewWrapper(cfg)
	log.Printf("api-go running with config: %v", w.Config() != nil)
}
```

Use `NewWrapper(cfg)` to wrap the loaded `*config.Config`. The `Provider` interface allows modules to depend on config without hardcoding env keys.

Secrets are automatically pulled from either `SECRET__<NAME>` or `<NAME>` to support `.env` files generated by config-thonnas.
